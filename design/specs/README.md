# UI/UX Specifications & Viewport Layouts
This directory holds detailed design specifications for Srishti's portfolio screens:
- Desktop Breakpoints: 1440px and 1920px (Canvas width clamped to 1440px with ambient forest vignetting)
- Tablet Breakpoints: 768px – 1024px
- Mobile Breakpoints: 390px (iPhone standard) and 414px
- Grid System: 12-column responsive grid on desktop with 24px gutters; 4-column responsive grid on mobile with 16px gutters.
- Navigation HUD: Fixed pill container `top: 1.5rem; max-width: 1100px;` with Recruiter Fast-Path links (`#work`, `#about`, `#resume`, `#contact`).

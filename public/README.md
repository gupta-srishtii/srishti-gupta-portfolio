# Published assets

Only explicitly public, approved portfolio media belongs in this directory.

For example, put an approved painting in `public/artwork/painting.webp` and use `/artwork/painting.webp` in `src/data/portfolio.ts`. Put an approved resume in `public/documents/resume.pdf` and set `profile.resume` to `/documents/resume.pdf`.

Do not copy the raw `assets` directory wholesale. Private mascot reference photos must stay in ignored `assets/mascot/references/` and must never be copied here.
